# GASF 组会图表中文版

本目录仅新增中文版，英文原图、脚本、原始日志、源码、配置与统计表均保留。全程本地处理，无网络访问或新依赖。

## 文件与范围

`figures/` 含 00 算法流程图、01 Mask 状态、02 命中比例、03 完整范围耗时、04 静态/动态学习、04b 学习进程、05 姿态多样性，共七张；`figures/latency_focus/` 另含 03 主体范围耗时修订版。八张均提供 `_zh.png`、`_zh.svg`、`_zh.pdf`，PNG 为 4800×2700、300 DPI。组会推荐使用 latency_focus 版本；完整范围版作为补充材料保留。

英文目录中的 pdf_check、before_after、comparison 和 overview 是质检/对照辅助图，不属于额外实验主题。中文版对应的辅助总览与 PDF 检查渲染放在 `qa/`。

## 复现

在仓库根目录执行：

```powershell
python visualization/group_meeting/zh/render_zh.py
```

依赖复用 `visualization/requirements.txt`。使用本地微软雅黑（Microsoft YaHei）；也支持已安装的 Noto Sans CJK SC 或 SimHei。SVG 保留可编辑文字，跨机器编辑需具备对应中文字体；PNG 无此要求，PDF 嵌入字体。

`translations_zh.json` 是可编辑的英中显示文字字典。实验 ID、数值、单位、话题、日志字段与技术缩写保持原样。Mask 命中比例不译为准确率，姿态分箱不译为覆盖率。

## 实现和验证

导入原有实验绘图函数，在内存中将文字对象替换为中文，再导出到本目录。延迟修订版和流程图通过 Python AST 提取现有 main 的读取/绘图部分，在原脚本首次导出之前截断；原脚本的写文件部分不执行。没有复制或改写解析与统计算法，没有执行英文图重新导出。

对每张图的曲线 x/y、散点坐标、图形路径、坐标范围在翻译前后计算指纹并比较。845 条记录及重新计算的统计 CSV 与原件逐字节一致。所有 178 种显示字符串均纳入翻译检查或明确的不翻译白名单。运行前后比较 142 个既有文件的 SHA-256；现有未提交算法流程图同样受到保护。详情见 `validation_zh.json`。

实际使用 plot-is-all-you-need 的既有风格参考、直接标注、文字层级、字体适配和 Appraisal 渲染复查；保留本会话已检查的图库参考与原图结构，不重新选择实验表达方式。八张 PNG 已目视检查，八张 SVG 已解析，八张 PDF 已用 Poppler 渲染。图中文字没有改变统计范围和科研解释限制。

报告注意：主体范围延迟图仍基于全部样本统计；2/845 个样本超过 3.2 ms，最大值 9.304 ms 来自 03_arc_A 第 1500 帧。流程图保持逻辑双分支而非两条 LiDAR 回调线程；当前 V1 不提供真实标签准确率结论。
